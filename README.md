# Sanketana GenAI Foundations: Starter

No installs needed. Everything runs in your browser.

## 1. Get your Gemini key (one time)
1. Go to https://aistudio.google.com and sign in.
2. Click **Get API key**, then **Create API key**. Copy it.
3. Don't share it with anyone or paste it into your code.

## 2. Open your coding space
1. Click this link: **https://codespaces.new/OWNER/genai-foundations-starter**
   (your teacher will replace OWNER with the right name)
2. When it asks for `GEMINI_API_KEY`, paste your key and click **Create codespace**.
3. Wait about a minute until you see the code editor.

## 3. Check everything works
In the terminal at the bottom, type:

    python check_setup.py

You should see **ALL GOOD**. If you see **FAIL**, take a screenshot and send it to your teacher.

## 4. Run your first app

    streamlit run app.py

Your app opens in a new browser tab. Type a question and press Enter.

To stop the app, click the terminal and press **Ctrl + C**.

## Coming back next time
Go to https://github.com/codespaces and open your existing codespace. Your work is saved there.
